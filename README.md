本科时大创做的项目，创新点在于老年人监护用nbiot远程传输，主控采用STM32单片机

手环作为从机具有测量心率、血氧、体温及呼救的功能，用蓝牙通信把检测到的数据传输到腰扣的主机上，腰扣用mpu6050检测摔倒，GPS定位并整合传输数据，利用腰扣中的 NB-IoT 模块进行远程数据传输到服务器。服务器运行TCP脚本，不断地获取并解析nbiot发送到端口的数据包保存到数据库中，方便可视化页面的展示

家庭环境监测不是我写的，但也是做了厌恶温湿度门磁空气质量等监测，利用WiFi模块传到服务器

web 网页端数据可视化平台，以便于子女实时查看家庭环境，老人身体状况等各种检测数据且能快速接收到老人发出的呼救信息。其中，web 网页端是基于Django框架搭建一个B/S的管理系统，前端使用了Bootstrap3 模板，后端使用Python开发语言，数据库使用的是MySQL，将其部署在阿里云平台。
